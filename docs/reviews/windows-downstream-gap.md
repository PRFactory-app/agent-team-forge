**WT follow-up detail.** `FollowUpJob` admits a new job against the parent's
recorded session (`A:src/AgentTeamForge.Business/Features/Jobs/FollowUpJob.cs:95-125`).
`WtInteractiveBackend.Start` takes and **stops** a retained tab, then creates a
new `InteractiveLaunch` carrying `ResumeSessionId` (`:47-67`); `WtTabControl`
starts a new WT/console wrapper (`A:src/AgentTeamForge.Business/Features/Agents/Terminals/WtTabControl.cs:37-99`).
The previous native session may resume, but the live agent process/tab is not
reused. By comparison, Linux Herdr has a retained-pane reuse path; it does not
establish Windows support.
