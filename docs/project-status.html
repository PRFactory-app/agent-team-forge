Run today on Linux

Build or publish the host using the pinned .NET 11 SDK, then choose a launch mode explicitly:

  • atf setup --mode headless --apply or atf setup --mode herdr --apply, then atf start. Herdr mode opens real interactive agent TUIs for Claude Code, Codex and Pi.
  • Submit, inspect, follow up, list and cancel jobs through MCP (submit_job, get_job, follow_up, list_jobs, stop_job) or atf client. The fake backend is available for local checks. Dispatch is bounded to eight concurrent jobs by default and preserves order per native session.
  • Read live output with get_job_output or atf client logs JOB_ID --follow, including Herdr transcripts. Use --worktree on submit for an isolated per-job Git checkout; follow-ups reuse it. Jobs support run timeouts, queue TTL and interrupting follow-ups. An idle failed or reconciled session can also be resumed when ownership checks pass.
  • atf client stop JOB_ID cancels one job; atf stop stops the owned daemon. Startup recovery uses pidfd-pinned cleanup for orphaned backend children. atf prune removes eligible jobs after 30 days by default; the daemon also sweeps daily. First start each boot attempts a SQLite backup and keeps the newest two backups.

Native wake commits the result before sending a notice to a detected Claude Code, Codex or Pi lead; the lead reads the job through MCP. Setup enables Claude crossSessionInbound. Codex may need register_codex_wake; Pi uses the bundled extension. See the Linux quickstart for exact build, setup and CLI commands, and the migration guide for tool mapping and the dogfood run.

Scope decisions

Agents run unattended with bypass permissions. Human approval relay, W7 multi-team scopes and the earlier contract ceremony were dropped by owner decision. Linux comes first; Windows and macOS need validation on their own machines. The PRFactory connector is optional, and local jobs need no external orchestrator.

Current limits

Herdr's server and pane binding is still held in memory, so the headless pidfd recovery claim does not imply full interactive tab recovery. Worktrees remain for manual cleanup when jobs are pruned. The web console, installer and Windows terminal port are not available from main yet.
